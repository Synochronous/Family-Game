MYSTERY EVENT SYSTEM

Mystery Event Weights

Events are rolled only when a question opens. The score-specific weights determine which mystery event is selected after the trigger roll.

JEOPARDY SPECIAL

Mystery Question Menu

Up to 12 mystery questions can be unlocked over the game. Each question has 8 answer choices and is worth $2,000–$5,000. The category is revealed after you choose the question. The mystery event is the unlock itself, and normal events cannot trigger on these questions.

BIRTHDAY BOY

Papa Question Menu

Choose one available Papa bundle. Every bundle contains 3 questions. Each subquestion receives its own randomized value, and all 3 correct doubles the total payout.

HOST CONTROLS

Host Help

During a question

Click an answer. Once an answer is chosen, the question is resolved and Continue appears.

Hints below $1,000 remove one wrong answer at a time and can be reused until no wrong answers remain. Each successful Hint raises that team's normal penalty chance by 10–16 percentage points. At $1,000+, the current player gets one 50/50 for the entire game.

Use Shift + 1–6 to deduct $500 from a specific team for a host-recorded broken curse.

Keyboard

1–4 / Q-W-A-S answer choices. Mystery questions also use 5–8.

Enter or C continues only after an answer has been recorded. F force-ends the unresolved question • L leaderboard • T roster • O event weights • Shift + 1–6 team deduction.

Special question unlock odds are hidden and only roll when the Mystery Question Menu is opened.

Mystery Questions

There are up to 12 future questions. Each has 8 answers and is worth $2,000–$5,000. A mystery event unlocks one question. At 6 or fewer normal questions remaining, all remaining mystery questions unlock together.

Birthday Boy

The board button opens the Papa bundle menu. Choose a bundle there instead of having the game silently pick one.
